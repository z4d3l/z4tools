# z4tools v1.5.3 (development snapshot)

unofficial terminal-based customization and management toolkit for [gpubrewlauncher](https://github.com/NiftyNova/GPUBrewLauncher).

> ⚠️ **work in progress:** this repository is being prepared from archived development builds. the full source has not yet been uploaded or verified against the current installed files on the developer's device. do not install from this repository until the source upload and verification are complete.

## features

- theme maker and advanced color editing
- live accent switching (requires compatible runtime and shader patches)
- saved theme restoration on launcher startup
- accent patch manager with confirmations and installed-patch detection
- cleaner terminal menu navigation
- compatibility checker (read-only)
- app deployment and management
- backups, launcher build tools, diagnostics, logs and startup timer
- app template generator, watermark customization, and text hot-reload

## environment

android termux is the primary development target. other linux environments are not yet verified.

## launch (after installation)

```bash
bash ~/z4tools/z4tools.sh
```

this command runs an existing installation. a clean installation guide will be provided once the source is uploaded and tested.
